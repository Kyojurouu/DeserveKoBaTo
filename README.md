# 💸 Deserve Ko Ba To?!? (The Financial Delusion Enabler)
**🥉 3rd Place Winner - GDG Manila "Build with AI" Hackathon (Chaos-to-Code Category)**

We all know Large Language Models can write complex code and analyze massive datasets. But we asked the most important question: *Can an AI mathematically justify why a broke student should buy a ₱200 Iced Matcha Latte when they only have ₱250 in their bank account?*

"Deserve Ko 'To" is an AI-powered agent designed to aggressively enable (or violently destroy) your financial delusions using advanced "Girl/Boy Math." 

## 🚀 The Chaos-to-Code Workflow
This project takes the universal daily annoyance of financial indecision and forces it into a strict, automated AI workflow:
1. **The Confession:** The user inputs their current bank balance, the item they want, its cost, and their pathetic excuse for buying it (e.g., *"I survived a 3-hour forensic lab without crying"*).
2. **The Delusion Engine (Agentic Logic):** The Gemini 1.5 Flash API evaluates the excuse. If deemed valid, it generates absurd but logically sound mathematical deductions to reduce the cost to ₱0.
3. **The CVS Receipt (Output):** The UI dynamically generates a digital "receipt" itemizing exactly how the AI justified the purchase, complete with a massive APPROVED or DENIED verdict.

## 🛠️ Tech Stack & Technical Depth
This isn't just a basic chatbot wrapper; it utilizes strict structured outputs to ensure UI stability.
* **Frontend:** Single-page HTML5, styled with Tailwind CSS for a modern, mobile-first UI.
* **Logic:** Vanilla JavaScript (ES6+).
* **AI Engine:** Google Gemini REST API (`gemini-1.5-flash`).
* **Technical Flex:** Implements strict JSON schema enforcement (`response_mime_type: "application/json"`) on the API call. The LLM does not return conversational text; it acts as a reasoning engine that returns a highly structured data array containing the verdict, passive-aggressive reasoning, and fractional cost deductions used to render the UI.
